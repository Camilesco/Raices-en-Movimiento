# 🌱 Raíces en Movimiento

Página web del estudio cualitativo sobre estudiantes universitarios foráneos en Bogotá.

---

## 🚀 Despliegue en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. Ve a [vercel.com](https://vercel.com) → **New Project** → importa tu repo.
3. Vercel detecta automáticamente que es HTML estático. Dale clic a **Deploy**.
4. ¡Listo! Tu URL quedará algo como `raices-en-movimiento.vercel.app`.

---

## 🗄️ Configurar Supabase (para el Foro)

Sigue estos pasos **antes** de hacer deploy para que el foro guarde y muestre los mensajes correctamente.

### Paso 1 — Crear cuenta y proyecto

1. Ve a [supabase.com](https://supabase.com) y crea una cuenta gratuita.
2. Haz clic en **New Project**.
3. Ponle un nombre (ej: `raices-en-movimiento`), elige una contraseña segura y selecciona la región **South America (São Paulo)** (la más cercana a Colombia).
4. Espera ~2 minutos a que el proyecto se inicialice.

---

### Paso 2 — Crear la tabla del foro

1. En tu proyecto de Supabase, ve al menú lateral → **SQL Editor**.
2. Haz clic en **New query** y pega este SQL:

```sql
create table foro_posts (
  id          bigint generated by default as identity primary key,
  created_at  timestamptz default now(),
  nombre      text not null,
  ciudad      text,
  mensaje     text not null
);

-- Permitir que cualquiera pueda leer y escribir (foro público)
alter table foro_posts enable row level security;

create policy "Lectura pública" on foro_posts
  for select using (true);

create policy "Escritura pública" on foro_posts
  for insert with check (true);
```

3. Haz clic en **Run** (▶). Debe aparecer "Success".

---

### Paso 3 — Obtener tus credenciales

1. En Supabase, ve a **Project Settings** (ícono de engranaje) → **API**.
2. Copia los dos valores:
   - **Project URL** → algo como `https://abcdefgh.supabase.co`
   - **anon public** key → una cadena larga que empieza con `eyJ...`

---

### Paso 4 — Actualizar el index.html

Abre `index.html` y busca estas líneas cerca del final (dentro del `<script>`):

```javascript
const SUPABASE_URL = 'TU_SUPABASE_URL';
const SUPABASE_KEY = 'TU_SUPABASE_ANON_KEY';
```

Reemplázalas con tus valores reales:

```javascript
const SUPABASE_URL = 'https://abcdefgh.supabase.co';
const SUPABASE_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';
```

Guarda el archivo.

---

### Paso 5 — Re-deploy

Si ya tenías el proyecto en Vercel, simplemente haz push a GitHub y Vercel redesplegará automáticamente.

## 📄 Agregar la Cartilla PDF

Cuando tengas el PDF de la cartilla listo, tienes dos opciones:

### Opción A — Carga local (sin servidor)
Los usuarios pueden cargar el PDF directamente en la página usando el botón **"Cargar PDF"** en la sección Cartilla. El PDF se muestra en el visor integrado.

### Opción B — PDF fijo en el sitio (recomendado)
1. Coloca el archivo PDF en la carpeta del proyecto: `cartilla.pdf`
2. En `index.html`, busca la función `cargarPDF` y agrega esta línea al final del `<script>`:

```javascript
// Cargar cartilla automáticamente al inicio
window.addEventListener('load', () => {
  const iframe = document.getElementById('cartilla-iframe');
  const placeholder = document.getElementById('cartilla-placeholder');
  iframe.src = 'cartilla.pdf';
  iframe.style.display = 'block';
  placeholder.style.display = 'none';
  document.getElementById('btn-fullscreen').style.display = 'inline-block';
  document.getElementById('btn-download').style.display = 'inline-block';
});
```

3. Sube `cartilla.pdf` junto con `index.html` a GitHub. Vercel lo servirá automáticamente.

## 🗺️ Actualizar la Cartografía Social

Cuando tengas la imagen real de la cartografía social:

1. Guarda la imagen en la carpeta del proyecto (ej: `cartografia.jpg`).
2. En `index.html`, busca el bloque `<svg ...>` dentro de la sección `#cartografia`.
3. Reemplaza todo el `<svg>...</svg>` con:

```html
<img src="cartografia.jpg" alt="Cartografía social - Bogotá" style="width:100%;display:block;" />
```
